# 🥤 Coca-Cola Power BI Dashboard

## 📊 Project Overview

This project contains an interactive **Coca-Cola Sales Dashboard** created using **Microsoft Power BI**.

The dashboard provides insights into Coca-Cola's sales performance, revenue, operating profit, product performance, and regional sales.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Track total revenue and profit
- Compare sales across different regions
- Analyze product-wise performance
- Identify top-performing products
- Visualize sales trends
- Generate business insights using interactive dashboards

---

## 🛠️ Tools & Technologies Used

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Visualization**
- **Data Analysis**

---

## 📈 Dashboard Features

The dashboard includes insights such as:

- 💰 Total Sales
- 📊 Operating Profit
- 📦 Units Sold
- 📈 Sales Trends
- 🌍 Regional Sales Analysis
- 🥤 Product-wise Sales
- 🏪 Retailer Performance
- 📅 Monthly Sales Analysis
